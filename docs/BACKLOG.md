# 챌룸 제품 백로그

핵심 루프: **챌린지 발견 → 방 생성/초대 → 함께 업로드 → 공유**.
현재 "발견"과 "업로드"는 꽤 갖춰져 있지만, **중간 관리**와 **재방문을 만드는 장치**가 비어 있다.
아래는 그 관점에서 정리한 다음 기능 후보들 — 우선순위 순.

## 1. 지금 당장 — 반쪽짜리 기능 완성

- [x] **방장의 신청 수락/거절 화면** — 멤버 화면 안에 "신청 대기 중" 섹션으로 구현.
- [x] **알림함(인앱 알림 목록)** — 홈 헤더 종 아이콘 + 안 읽음 배지. 케이스 6종(신청 도착·수락됨·거절됨·댓글·새 멤버·새 챌린지) 문구/아이콘 정리, 신청 수락은 실시간으로도 쌓인다.
- [x] **신고(동영상)** — 챌린지 원본 영상(상세 "⋮")과 제출 영상(그리드 칸 "⋮")에서 신고 가능. 사유 6종 + 자세히 적기(선택) + 접수 완료 화면.
- [ ] **차단** — 신고와 짝인 "이 사람 콘텐츠 안 보기"는 아직 없다.

## 2. 다시 켜게 만드는 장치 (Retention)

- [ ] **제출 마감일 + 카운트다운**
  지금 챌린지는 무기한이라 "오늘 안 하면 늦는다"는 압박이 없다.
  마감이 있어야 리마인더 알림도, 긴장감도 생긴다.
- [x] **영상 좋아요** — 챌린지 원본 영상 + 제출 영상 그리드 칸 모두에서 하트로 토글. 댓글과 같은 자리(원본은 댓글 줄 왼쪽, 제출 영상은 그리드 칸 배지)에 놓았다.
- [ ] **연속 참여 스트릭 · 뱃지** (가벼운 게이미피케이션)

## 3. 발견성 & 바이럴

- [ ] **검색** — 지금은 카테고리 칩으로만 거른다. 방 이름/해시태그 검색이 없다.
- [ ] **진짜 공유 기능** — "공유" 아이콘이 지금 "준비 중" 스텁이다.
  카톡 공유 등으로 앱 밖 친구를 끌어오는 통로가 없다는 뜻이라 아쉽다.

## 4. 프로필 강화

- [ ] **자기소개 + 관심 카테고리**
  온보딩에서 몇 개 고르면 홈 피드 추천에 반영.
- [ ] **내가 참여한 챌린지 히스토리**
  포트폴리오처럼 쌓이면 성취감을 주고, 프로필을 볼 이유도 생긴다.
- [ ] **팔로우 관계** (선택) — 방을 넘나드는 소셜 그래프. 지금 규모엔 오버스펙일 수 있음.

## 5. 방장 도구

- [x] 신청 수락/거절 (1번과 동일 항목)
- [ ] 마감 연장
- [ ] 멤버에게 리마인드 보내기

---

"지금 당장" 항목은 이제 **차단**만 남았다. 그다음은 재방문 유도(마감일·좋아요) 또는 발견성(검색·공유) 쪽을 보면 좋다.
